# Run bundled GeoGon as a temporary tool workspace

PatterDraw will expose the pinned, locally bundled GeoGon application only through a default-off experimental Math Tools dialog. The iframe exists only while the wrapper-owned dialog is open and is never stored in a PatterDraw project; GeoGon's own device-local working state also remains outside that project. Inserting creates a sanitized local SVG board asset, never a persisted iframe or arbitrary web embed. The direct same-origin export API means the pinned GeoGon runtime is trusted vendor code, not hostile content isolated by the iframe sandbox; release-time hash verification and the child application's no-connect CSP enforce that trust decision. This preserves PatterDraw's offline project and export guarantees while avoiding a high-risk rewrite of GeoGon's document-owned WebGL application into React.
